# Hint bar — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One row along the bottom of the frame naming what the focused panel responds to.

**Architecture:** `Panel` owns its bindings as `&'static [Binding]` keyed by real
`Key` values, so a property test can press every hint the bar shows and require
it to do something. The domain renders those keys to labels and projects a
`HintBar` on the `ViewModel`; `lc-inbound` composes, truncates, and draws it. The
bar's row comes out of `layout`, which raises its floor by one so the row is
always there and never has to be dropped.

**Tech Stack:** Rust, `ratatui` 0.30.2, no new dependencies.

**Spec:** [doc/specs/2026-08-09-hint-bar-design.md](../specs/2026-08-09-hint-bar-design.md)

**Depends on:** the minimum size slice
([design](../specs/2026-08-09-minimum-terminal-size-design.md)), already
implemented — `layout` returns `Shell::Panels | Shell::TooSmall` behind a 40×6
floor. Task 2 raises that floor to 40×7.

## Global Constraints

- `AGENTS.md` non-negotiables apply to every task: no `unsafe`, no narrating
  comments, no warnings, no ignored tests, no `#[allow]` without a reason.
- `lc-domain` gains no dependency. Tasks 1 and 3 touch it; neither needs one.
  `lc-domain` must never see `ratatui` or `crossterm`.
- `mise run ci` must be clean before a task is considered done. Individual
  steps use `cargo test -p <crate>` for speed; the last step of each task runs
  the gate.
- Conventional Commits, imperative, lowercase, no trailing period.
- Test names are sentences about behaviour, never `test_foo`.
- `unwrap`/`expect` are banned outside tests; `clippy.toml` permits them inside.
- The domain names meanings, never colours (architecture.md §6). A new visual
  distinction is a `Token`, not a `Style` in `render.rs`.
- Every label in the bar is produced by the `label` function of Task 1. No task
  writes `"j/k"` as a literal in non-test code.

```rust
//! What the focused panel responds to, as the bar will say it.

use crate::model::Key;
use crate::state::Panel;

/// A binding, keyed by the values `handle_key` actually matches on.
///
/// Not a display string: a string could name a key no arm of `handle_key`
/// claims and nothing would ever catch it, and a bar that lies is worse than
/// no bar (design §2). `update::tests` presses every one of these.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Binding {
    pub keys: &'static [Key],
    pub action: &'static str,
}

/// One binding, as text, for a renderer that never sees a [`Key`].
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Hint {
    pub keys: String,
    pub action: &'static str,
}

/// What the focused panel contributes to the bar.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum HintGroup {
    Keys(Vec<Hint>),
    /// A panel that responds to nothing yet, saying so rather than drawing
    /// an empty group the reader has to interpret.
    Idle(&'static str),
}

/// What the focused panel does, and what works everywhere.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct HintBar {
    pub panel: HintGroup,
    pub global: Vec<Hint>,
}

/// Bindings every panel answers to. Repeated in each panel's bar rather than
/// learned once: a user who never presses `tab` has no way to find the other
/// three panels (design §3).
pub(crate) const GLOBAL: &[Binding] = &[
    Binding {
        keys: &[Key::Tab],
        action: "panel",
    },
    Binding {
        keys: &[Key::Char('q')],
        action: "quit",
    },
];

pub(crate) fn bar(focus: Panel) -> HintBar {
    HintBar {
        panel: match focus.hints() {
            [] => HintGroup::Idle("nothing here yet"),
            bindings => HintGroup::Keys(bindings.iter().map(rendered).collect()),
        },
        global: GLOBAL.iter().map(rendered).collect(),
    }
}

fn rendered(binding: &Binding) -> Hint {
    Hint {
        keys: label(binding.keys),
        action: binding.action,
    }
}

fn label(keys: &[Key]) -> String {
    keys.iter().map(name).collect::<Vec<_>>().join("/")
}

/// Named rather than drawn, for the keys with no printable form: the arrow
/// glyphs collide with each other, and a terminal font may draw any of them
/// as a box (design §3).
fn name(key: &Key) -> String {
    match key {
        Key::Char(' ') => "space".to_owned(),
        Key::Char(character) => character.to_string(),
        Key::Enter => "⏎".to_owned(),
        Key::Escape => "esc".to_owned(),
        Key::Backspace => "bksp".to_owned(),
        Key::Tab => "tab".to_owned(),
        Key::BackTab => "shift-tab".to_owned(),
        Key::Delete => "del".to_owned(),
        Key::Insert => "ins".to_owned(),
        Key::Home => "home".to_owned(),
        Key::End => "end".to_owned(),
        Key::PageUp => "pgup".to_owned(),
        Key::PageDown => "pgdn".to_owned(),
        Key::Up => "↑".to_owned(),
        Key::Down => "↓".to_owned(),
        Key::Left => "←".to_owned(),
        Key::Right => "→".to_owned(),
        Key::F(number) => format!("F{number}"),
    }
}
```

`name` is an exhaustive match, so a new `Key` variant cannot compile until it
says how it is written.

```rust
//! The hint bar: what the focused panel responds to, along the bottom row.

use lc_domain::style::Token;
use lc_domain::view::{Hint, HintBar, HintGroup};
use ratatui::text::{Line, Span};

use crate::theme::Theme;

const INDENT: &str = " ";
const GAP: &str = "  ";
const SEPARATOR: &str = " │ ";

/// The bar as it fits in `width`.
///
/// Hints are dropped whole rather than clipped, lowest value first: panel
/// hints right to left, then `tab panel`, then the first panel hint with the
/// separator. `q quit` goes last, because a user who can read one hint needs
/// the way out (design §6).
pub(crate) fn line(bar: &HintBar, width: u16, theme: Theme) -> Line<'static> {
    let panel = panel_segments(&bar.panel);
    let global: Vec<Segment> = bar.global.iter().map(Segment::hint).collect();
    let (kept, from) = fit(&panel, &global, usize::from(width));

    Line::from(spans(&panel[..kept], &global[from..], theme))
}

enum Segment {
    Hint { keys: String, action: String },
    /// A panel with no bindings, saying so. Carries no key to draw.
    Sentence(String),
}

impl Segment {
    fn hint(hint: &Hint) -> Self {
        Self::Hint {
            keys: hint.keys.clone(),
            action: hint.action.to_owned(),
        }
    }

    /// Columns, on the assumption every label is single-width — true of the
    /// ASCII names and of `⏎`, which is the only glyph `label` produces.
    fn width(&self) -> usize {
        match self {
            Self::Hint { keys, action } => {
                keys.chars().count() + 1 + action.chars().count()
            }
            Self::Sentence(text) => text.chars().count(),
        }
    }

    fn spans(&self, theme: Theme) -> Vec<Span<'static>> {
        match self {
            Self::Hint { keys, action } => vec![
                Span::styled(keys.clone(), theme.style(Token::HintKey)),
                Span::styled(format!(" {action}"), theme.style(Token::HintAction)),
            ],
            Self::Sentence(text) => {
                vec![Span::styled(text.clone(), theme.style(Token::HintAction))]
            }
        }
    }
}

fn panel_segments(group: &HintGroup) -> Vec<Segment> {
    match group {
        HintGroup::Keys(hints) => hints.iter().map(Segment::hint).collect(),
        HintGroup::Idle(text) => vec![Segment::Sentence((*text).to_owned())],
    }
}

fn fit(panel: &[Segment], global: &[Segment], width: usize) -> (usize, usize) {
    let mut kept = panel.len();
    let mut from = 0;

    while kept > 1 && composed(panel, kept, global, from) > width {
        kept -= 1;
    }
    if composed(panel, kept, global, from) > width && from + 1 < global.len() {
        from += 1;
    }
    if composed(panel, kept, global, from) > width {
        kept = 0;
    }
    if composed(panel, kept, global, from) > width {
        from = global.len();
    }

    (kept, from)
}

fn composed(panel: &[Segment], kept: usize, global: &[Segment], from: usize) -> usize {
    if kept == 0 && from >= global.len() {
        return 0;
    }

    let separator = if kept > 0 && from < global.len() {
        SEPARATOR.chars().count()
    } else {
        0
    };

    INDENT.chars().count() + joined(&panel[..kept]) + separator + joined(&global[from..])
}

fn joined(segments: &[Segment]) -> usize {
    segments.iter().map(Segment::width).sum::<usize>()
        + GAP.chars().count() * segments.len().saturating_sub(1)
}

fn spans(panel: &[Segment], global: &[Segment], theme: Theme) -> Vec<Span<'static>> {
    if panel.is_empty() && global.is_empty() {
        return Vec::new();
    }

    let mut spans = vec![Span::raw(INDENT)];
    push_joined(&mut spans, panel, theme);
    if !panel.is_empty() && !global.is_empty() {
        spans.push(Span::styled(SEPARATOR, theme.style(Token::HintAction)));
    }
    push_joined(&mut spans, global, theme);
    spans
}

fn push_joined(spans: &mut Vec<Span<'static>>, segments: &[Segment], theme: Theme) {
    for (index, segment) in segments.iter().enumerate() {
        if index > 0 {
            spans.push(Span::raw(GAP));
        }
        spans.extend(segment.spans(theme));
    }
}
```
