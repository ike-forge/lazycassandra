# Themes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the theme from a match arm per token into a `Palette` of named
colour roles, ship a richer default plus four Catppuccin flavours, and let the
user switch between them at runtime with live preview.

**Architecture:** `lc-domain` gains five style tokens and a `ThemeChoice` enum —
names, never colours (architecture.md §6). `lc-inbound` gains a `Palette`
struct and one `Token -> Style` function shared by every flavour, so a new
theme is a new `const Palette`. The picker is an `Overlay` like the command
palette, and live preview costs one field: the choice to restore on `Esc`.

**Tech Stack:** Rust 2024, `ratatui` 0.30.2, `crossterm` via `ratatui`. No new
dependencies.

**Spec:** [doc/specs/2026-08-10-themes-design.md](../specs/2026-08-10-themes-design.md).
Read it before Task 1; every task below cites the section it implements.

## Global Constraints

- `mise run ci` must be clean before a task is done. Zero warnings, zero
  failing or ignored tests (AGENTS.md).
- `unsafe_code = "forbid"`. No FFI.
- `lc-domain` must not depend on `ratatui`, `crossterm` or `tokio`. It names no
  colour — only meanings (`Token`) and theme names (`ThemeChoice`).
- No narrating comments. Comments are for edge cases, past bugs, upstream
  defects, and semantics the code cannot express (conventions.md).
- Conventional Commits, imperative, lowercase, no trailing period. Scope is the
  crate area: `feat(theme)`, `test(theme)`, `docs(vision)`.
- Commit after every task. Never `pull`, never `push`.
- No `unwrap()` outside tests.
- Public items in `lc-domain` carry doc comments.

```rust
//! WCAG relative luminance and contrast, for the palette tests.
//!
//! Test-only: a palette is a table of constants, and the thing worth asserting
//! about a table of constants is that someone can read it.

use ratatui::style::Color;

/// WCAG 2.x relative luminance.
pub(crate) fn luminance(color: Color) -> f64 {
    let Color::Rgb(red, green, blue) = color else {
        panic!("every palette role is a Color::Rgb, got {color:?}");
    };

    0.2126 * channel(red) + 0.7152 * channel(green) + 0.0722 * channel(blue)
}

fn channel(value: u8) -> f64 {
    let value = f64::from(value) / 255.0;

    if value <= 0.040_45 {
        value / 12.92
    } else {
        ((value + 0.055) / 1.055).powf(2.4)
    }
}

/// WCAG 2.x contrast ratio, `1.0` for identical colours and `21.0` for black
/// against white.
pub(crate) fn ratio(a: Color, b: Color) -> f64 {
    let (a, b) = (luminance(a), luminance(b));
    let (lighter, darker) = if a > b { (a, b) } else { (b, a) };

    (lighter + 0.05) / (darker + 0.05)
}

pub(crate) const BLACK: Color = Color::Rgb(0x00, 0x00, 0x00);
pub(crate) const WHITE: Color = Color::Rgb(0xff, 0xff, 0xff);

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn black_against_white_is_the_maximum_ratio() {
        assert!((ratio(BLACK, WHITE) - 21.0).abs() < 0.01);
    }

    #[test]
    fn a_colour_against_itself_is_the_minimum_ratio() {
        assert!((ratio(WHITE, WHITE) - 1.0).abs() < 0.001);
    }

    #[test]
    fn the_ratio_does_not_depend_on_which_way_round_it_is_asked() {
        let grey = Color::Rgb(0x7a, 0x7f, 0x8f);

        assert!((ratio(grey, WHITE) - ratio(WHITE, grey)).abs() < 0.001);
    }

    /// The mid-grey web accessibility guidance names as the 4.5:1 boundary
    /// against white. Pins the transfer function rather than the arithmetic
    /// around it — a linear channel would put this near 3.
    #[test]
    fn the_transfer_function_is_srgb_rather_than_linear() {
        let ratio = ratio(Color::Rgb(0x76, 0x76, 0x76), WHITE);

        assert!((4.4..=4.7).contains(&ratio), "{ratio}");
    }
}
```

```rust
//! Semantic tokens into concrete styles.
//!
//! A theme is a [`Palette`] — a table of named colour roles — and one mapping
//! from [`Token`] to a style, shared by every theme. Adding a theme is adding
//! a `const Palette`, not a match arm per token
//! (doc/specs/2026-08-10-themes-design.md §3).
//!
//! Four roles are `Option<Color>`. `None` is not "no colour": it is *not ours
//! to set*, which is how vision.md §4 principle 5 is stated in the type system
//! rather than in a comment.

mod catppuccin;
mod default;

#[cfg(test)]
mod contrast;

use lc_domain::posture::Posture;
use lc_domain::style::{Severity, Token};
use ratatui::style::{Color, Modifier, Style};

/// One theme's colours, by the meaning each is spent on.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct Palette {
    /// The whole frame. `None` leaves the terminal's own.
    pub(crate) base: Option<Color>,
    /// An overlay, so it separates from the field it covers.
    pub(crate) surface: Option<Color>,
    /// Body text, and `Severity::Info`.
    pub(crate) text: Option<Color>,
    pub(crate) border: Option<Color>,
    /// The cursor row's background.
    pub(crate) highlight: Color,
    /// The cursor row's text, where the theme cannot guarantee its own roles
    /// read against `highlight` (design §3.1). `None` keeps the row's own
    /// column colours; `Some` flattens them for legibility.
    pub(crate) highlight_text: Option<Color>,
    pub(crate) muted: Color,
    pub(crate) partition: Color,
    pub(crate) clustering: Color,
    pub(crate) keyspace: Color,
    pub(crate) table: Color,
    pub(crate) property: Color,
    pub(crate) accent: Color,
    pub(crate) match_: Color,
    pub(crate) success: Color,
    pub(crate) warning: Color,
    pub(crate) danger: Color,
    pub(crate) keyword: Color,
    pub(crate) reference: Color,
    pub(crate) literal: Color,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Theme {
    palette: &'static Palette,
}

impl Default for Theme {
    fn default() -> Self {
        Self {
            palette: &default::DEFAULT,
        }
    }
}

impl Theme {
    pub(crate) const fn palette(self) -> &'static Palette {
        self.palette
    }

    #[must_use]
    pub fn style(self, token: Token) -> Style {
        let palette = self.palette;

        match token {
            Token::PartitionKey => fg(palette.partition).add_modifier(Modifier::BOLD),
            Token::ClusteringKey => fg(palette.clustering),
            Token::Keyspace => fg(palette.keyspace),
            Token::Table => fg(palette.table),
            Token::RegularColumn | Token::Severity(Severity::Info) => maybe(palette.text),
            Token::Posture(Posture::ReadOnly) => maybe(palette.text),
            Token::Posture(Posture::Writable) => fg(palette.success),
            Token::Posture(Posture::Protected) => {
                fg(palette.danger).add_modifier(Modifier::BOLD)
            }
            Token::Severity(Severity::Warning) => fg(palette.warning),
            Token::Severity(Severity::Danger) => fg(palette.danger).add_modifier(Modifier::BOLD),
            Token::PropertyName => fg(palette.property),
            Token::Muted | Token::HintAction => fg(palette.muted),
            // Bold rather than a colour: focus must not compete with the
            // colours that carry meaning, and it has to read on a panel border
            // the theme may have coloured already.
            Token::Focused | Token::HintKey => Style::new().add_modifier(Modifier::BOLD),
            Token::Shortcut => Style::new().add_modifier(Modifier::UNDERLINED),
            Token::Selected => selected(palette),
            // `fg` alone, so it survives being patched under the row's
            // highlight style: the cursor's row can contain matches, and both
            // must still read.
            Token::Match => fg(palette.match_).add_modifier(Modifier::BOLD),
            // A modifier rather than a colour, because it has to read
            // *against* the highlighted row whatever colour that row is.
            Token::SelectedCell => Style::new()
                .add_modifier(Modifier::REVERSED)
                .add_modifier(Modifier::UNDERLINED),
            Token::Keyword => fg(palette.keyword),
            Token::Reference => fg(palette.reference),
            Token::Literal => fg(palette.literal),
        }
    }
}

/// The cursor row.
///
/// A background alone leaves the row's own colours alone, which is what a
/// theme that has verified its palette wants. A theme that cannot know what it
/// is drawn over spends a foreground too and gives those colours up for the
/// one row (design §3.1).
fn selected(palette: &Palette) -> Style {
    let style = Style::new().bg(palette.highlight);

    match palette.highlight_text {
        Some(color) => style.fg(color),
        None => style,
    }
}

fn fg(color: Color) -> Style {
    Style::new().fg(color)
}

fn maybe(color: Option<Color>) -> Style {
    match color {
        Some(color) => Style::new().fg(color),
        None => Style::new(),
    }
}
```

```rust
//! The theme that wears the terminal's clothes.
//!
//! `base`, `surface`, `text` and `border` are `None`: the background and the
//! body foreground are the user's, and this theme paints over neither
//! (vision.md §4, principle 5).
//!
//! Every colour below is drawn on top of a background this theme cannot see,
//! so each holds a WCAG contrast ratio of at least 3.0 against black *and*
//! against white. That is a narrow band — a relative luminance of roughly
//! 0.10 to 0.30 — and it is why these are deeper than a palette designed for
//! one background would be (design §4).

use ratatui::style::Color;

use super::Palette;

const AMBER: Color = Color::Rgb(0xc9, 0x82, 0x1f);
const TEAL: Color = Color::Rgb(0x10, 0x84, 0x7c);
const MAUVE: Color = Color::Rgb(0x8a, 0x4f, 0xd4);
const BLUE: Color = Color::Rgb(0x2b, 0x6f, 0xd8);
const MAGENTA: Color = Color::Rgb(0xb8, 0x48, 0x9a);
const RUST: Color = Color::Rgb(0xd1, 0x66, 0x2f);
const OLIVE: Color = Color::Rgb(0x5f, 0x8f, 0x16);
const GREY: Color = Color::Rgb(0x7a, 0x7f, 0x8f);
const GREEN: Color = Color::Rgb(0x2e, 0x8b, 0x4f);
const OCHRE: Color = Color::Rgb(0xa8, 0x78, 0x1a);
const RED: Color = Color::Rgb(0xc8, 0x32, 0x2f);

pub(crate) const DEFAULT: Palette = Palette {
    base: None,
    surface: None,
    text: None,
    border: None,
    highlight: Color::Rgb(0x45, 0x48, 0x5a),
    highlight_text: Some(Color::Rgb(0xe8, 0xea, 0xf2)),
    muted: GREY,
    partition: AMBER,
    clustering: TEAL,
    keyspace: MAUVE,
    table: BLUE,
    property: MAGENTA,
    accent: RUST,
    match_: OLIVE,
    success: GREEN,
    warning: OCHRE,
    danger: RED,
    keyword: MAUVE,
    reference: BLUE,
```

```rust
mod tests {
    use super::*;
    use crate::theme::contrast::{BLACK, WHITE, ratio};

    /// Every role a theme can spend on text. `base`, `surface` and
    /// `highlight` are what text is drawn *on* and are absent by design.
    fn foregrounds(palette: &Palette) -> Vec<(&'static str, Color)> {
        vec![
            ("muted", palette.muted),
            ("partition", palette.partition),
            ("clustering", palette.clustering),
            ("keyspace", palette.keyspace),
            ("table", palette.table),
            ("property", palette.property),
            ("accent", palette.accent),
            ("match_", palette.match_),
            ("success", palette.success),
            ("warning", palette.warning),
            ("danger", palette.danger),
            ("keyword", palette.keyword),
            ("reference", palette.reference),
            ("literal", palette.literal),
        ]
    }

    #[test]
    fn the_default_theme_paints_no_panel_field() {
        let palette = Theme::default().palette();

        assert_eq!(palette.base, None, "the background is the user's");
        assert_eq!(palette.surface, None);
        assert_eq!(palette.text, None, "so is the body foreground");
        assert_eq!(palette.border, None);
    }

    #[test]
    fn the_cursor_row_is_the_only_token_that_paints_a_background() {
        let theme = Theme::default();

        for token in EVERY_TOKEN {
            let background = theme.style(token).bg;

            if matches!(token, Token::Selected) {
                assert!(background.is_some(), "the cursor row is a bar");
            } else {
                assert_eq!(background, None, "{token:?} painted over the user's field");
            }
        }
    }

    #[test]
    fn the_default_palette_reads_on_black_and_on_white() {
        let palette = Theme::default().palette();

        for (role, color) in foregrounds(palette) {
            for (name, ground) in [("black", BLACK), ("white", WHITE)] {
                let ratio = ratio(color, ground);
                assert!(
                    ratio >= 3.0,
                    "{role} is {ratio:.2} against {name}; \
                     this theme does not know which it is on"
                );
            }
        }
    }

    #[test]
    fn the_default_cursor_row_carries_its_own_foreground() {
        let palette = Theme::default().palette();
        let text = palette
            .highlight_text
            .expect("a theme that cannot see its background must not rely on it");

        let ratio = ratio(text, palette.highlight);
        assert!(ratio >= 4.5, "{ratio:.2}");
    }

    #[test]
    fn focus_is_drawn_without_spending_a_colour() {
        let style = Theme::default().style(Token::Focused);

        assert!(style.add_modifier.contains(Modifier::BOLD));
        assert_eq!(style.fg, None, "focus must not compete with meaning");
    }

    #[test]
    fn a_shortcut_is_underlined_without_spending_a_colour() {
        let style = Theme::default().style(Token::Shortcut);

        assert!(style.add_modifier.contains(Modifier::UNDERLINED));
        assert_eq!(style.fg, None);

        let theme = Theme::default();
        let cell = theme.style(Token::SelectedCell);

        assert_ne!(theme.style(Token::Selected).add_modifier, cell.add_modifier);
        assert_eq!(cell.fg, None);
        assert_eq!(cell.bg, None);

    #[test]
    fn a_match_is_legible_over_a_selected_row() {
        let theme = Theme::default();

        assert_ne!(matched, theme.style(Token::Selected));
        assert_eq!(
```

```rust
//! Which theme is on.
//!
//! A name, never a colour: the mapping from one of these to a palette lives in
//! `lc-inbound`, which is what keeps the domain free of a terminal
//! (architecture.md §6).

/// A theme the user can choose.
///
/// Declaration order is the order the picker lists them: the default first,
/// then the flavours lightest to darkest.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum ThemeChoice {
    /// Wears the terminal's own background and body text
    /// (vision.md §4, principle 5).
    #[default]
    TerminalDefault,
    CatppuccinLatte,
    CatppuccinFrappe,
    CatppuccinMacchiato,
    CatppuccinMocha,
}

impl ThemeChoice {
    /// Every theme, in the order the picker lists them.
    pub const ALL: [Self; 5] = [
        Self::TerminalDefault,
        Self::CatppuccinLatte,
        Self::CatppuccinFrappe,
        Self::CatppuccinMacchiato,
        Self::CatppuccinMocha,
    ];

    /// What the picker calls it.
    #[must_use]
    pub const fn label(self) -> &'static str {
        match self {
            Self::TerminalDefault => "Terminal default",
            Self::CatppuccinLatte => "Catppuccin Latte",
            Self::CatppuccinFrappe => "Catppuccin Frappé",
            Self::CatppuccinMacchiato => "Catppuccin Macchiato",
            Self::CatppuccinMocha => "Catppuccin Mocha",
        }
    }

    /// Where `self` sits in [`Self::ALL`].
    #[must_use]
    pub fn index(self) -> usize {
        Self::ALL
            .iter()
            .position(|choice| *choice == self)
            .unwrap_or(0)
    }
}
```

```rust
        return;

/// What an open picker responds to.
///
/// Moving the cursor sets the theme, so the frame underneath is the preview —
/// the same live-as-you-type rule the search prompt follows (panel search
/// design §1).
fn themes_key(state: &mut State, key: Key) -> Vec<Effect> {
    match key {
        Key::Char('q') => return quit(state),
        Key::Enter => {
            state.overlay = None;
            return Vec::new();
        }
        Key::Escape => {
            if let Some(Overlay::Themes { restored, .. }) = state.overlay {
                state.theme = restored;
            }
            state.overlay = None;
            return Vec::new();
        }
        _ => {}
    }

    let last = ThemeChoice::ALL.len();
    let Some(Overlay::Themes { cursor, .. }) = &mut state.overlay else {
        return Vec::new();
    };

    match key {
        Key::Char('j') | Key::Down => cursor.down(last),
        Key::Char('k') | Key::Up => cursor.up(),
        Key::Home => cursor.to_start(),
        Key::End => cursor.to_end(last),
        _ => {}
    }

    if let Some(Overlay::Themes { cursor, .. }) = &state.overlay
        && let Some(choice) = ThemeChoice::ALL.get(cursor.index())
    {
        state.theme = *choice;
    }

    Vec::new()
}
```

```rust
//! The theme picker: every theme, drawn over the panels.
//!
//! Narrower and shorter than the command palette, and gated on the palette's
//! own room rather than its own (`update::open_themes`) — a frame that holds
//! the larger block holds this one.

use ratatui::Frame;
use ratatui::layout::{Margin, Rect};
use ratatui::widgets::{Block, BorderType, Clear, List, ListItem, ListState};

use lc_domain::style::Token;

use crate::theme::Theme;

const WIDTH: u16 = 28;
const PAD: u16 = 1;

/// Where a picker listing `rows` themes goes in `area`, or `None` when it does
/// not fit.
fn rect(area: Rect, rows: usize) -> Option<Rect> {
    let height = u16::try_from(rows.saturating_add(2)).unwrap_or(u16::MAX);

    if area.width < WIDTH || area.height < height {
        return None;
    }

    Some(Rect::new(
        area.x + (area.width - WIDTH) / 2,
        area.y + (area.height - height) / 2,
        WIDTH,
        height,
    ))
}

pub(crate) fn render(frame: &mut Frame, labels: &[&str], selected: usize, theme: Theme) {
    let Some(area) = rect(frame.area(), labels.len()) else {
        return;
    };

    let block = Block::bordered()
        .border_type(BorderType::Rounded)
        .border_style(theme.border_style())
        .title("Theme");
    let inner = block.inner(area).inner(Margin {
        horizontal: PAD,
        vertical: 0,
    });

    frame.render_widget(Clear, area);
    frame.buffer_mut().set_style(area, theme.overlay_ground());
    frame.render_widget(block, area);

    let items: Vec<ListItem> = labels
        .iter()
        .map(|label| ListItem::new((*label).to_owned()))
        .collect();
    let mut state = ListState::default().with_selected(Some(selected));

    frame.render_stateful_widget(
        List::new(items).highlight_style(theme.style(Token::Selected)),
        inner,
        &mut state,
    );
}
```
